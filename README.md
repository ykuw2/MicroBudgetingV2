# MicroBudgetingV2
An iOS app where you can track your spending overtime by categorizing each day as low, medium, or high spending.
The use for this app is so that users can keep track of their spending (if they felt they spent too much, so-so, or low), so that they can improve their spending habits.

## The App
### Setting up the Notification
After inputting your name, you can set a specific time to set when the app should send a notification so that you make sure to track your spending (make sure to allow notification!).
